Privacy Policy

Daily Random Bot · Effective 13 October 2026

1. Overview

Daily Random Bot selects one non-bot Discord server member at random each day and posts a mention in a configured channel. This policy describes the behavior of the current bot code.

2. Information Processed

To perform selection, the bot accesses Discord server member information made available through the Discord API, including user IDs, usernames, and bot status. It uses the selected user’s ID to create a Discord mention. It also accesses the configured server and channel identifiers.

3. How Information Is Used

Member information is used solely to build the eligible-member list, select a random member, and send the daily message or an administrator-initiated test message.

4. Storage and Retention

The current bot code does not create a database or persist member lists or selection history. It prints the selected member’s username to the local application console, where logs may be retained by the operator or hosting provider. Discord retains messages and related data under its own policies.

5. Sharing

The bot sends the selected member’s mention and the custom message to the configured Discord channel. The current bot code does not independently sell member data or send it to third-party analytics services. Discord processes data as part of operating its platform.

6. Choices and Requests

Server administrators can disable the bot or remove it from the server. Members with privacy questions or requests about operator-controlled logs should contact the server administrator or bot operator. Discord message retention and deletion are subject to Discord’s features and policies.

7. Security

The operator should keep the bot token confidential, restrict channel permissions, and use appropriate security measures. No service can guarantee absolute security.

8. Changes and Contact

This policy should be updated if the bot begins storing information, adds features, or changes providers. Contact the server administrator or bot operator through the Discord server. Effective date: 13 October 2026.
